# LogiCondo - Sistema de Controle de Entregas

Sistema criado para resolver um problema real da portaria onde trabalho como porteiro.

### O problema:
Perda de controle de encomendas, moradores reclamando que não foram avisados.

### A solução:
Sistema web simples para registrar e controlar todas as entregas.

### Funcionalidades:
- Cadastro de encomenda por bloco e apartamento
- Registro de data e hora de chegada
- Controle de retirada com nome do morador
- Histórico de entregas

### Tecnologias:
HTML, CSS e JavaScript
